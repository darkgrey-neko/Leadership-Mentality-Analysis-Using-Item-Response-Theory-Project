# Leadership Mentality Analysis Using Item Response Theory

A statistical analysis project applying Item Response Theory (IRT) to evaluate leadership mentality based on respondents' responses to a structured assessment instrument.

The project focuses on examining the characteristics of assessment items and estimating respondents' latent leadership mentality levels using an IRT-based approach.

## Project Overview

Leadership mentality is a latent characteristic that cannot be observed directly and therefore needs to be measured through a set of indicators or assessment items.

This project applies Item Response Theory (IRT) to analyze the relationship between respondents' latent leadership mentality and their responses to assessment items.

Unlike classical scoring approaches that primarily rely on total scores, IRT provides a more detailed evaluation by considering the characteristics of individual items and respondents' latent ability or trait levels.

## Objectives

The main objectives of this project are to:

- Measure respondents' latent leadership mentality using Item Response Theory.
- Evaluate the characteristics and quality of assessment items.
- Identify items that provide useful information for measuring leadership mentality.
- Estimate respondents' latent trait levels based on their response patterns.
- Examine how well individual items differentiate respondents with different leadership mentality levels.
- Visualize and interpret the results of the IRT analysis.

## Methodology

The analysis generally includes the following stages:

1. Data preparation and response coding.
2. Exploratory analysis of respondents' item responses.
3. Selection and estimation of the Item Response Theory model.
4. Evaluation of item parameters.
5. Estimation of respondents' latent trait scores.
6. Evaluation of item and test information.
7. Visualization and interpretation of the IRT results.

## Analysis Output

The analysis may include several statistical outputs and visualizations, such as:

- Item parameter estimates
- Respondent latent trait estimates
- Item Characteristic Curves (ICC)
- Item Information Curves (IIC)
- Test Information Function
- Distribution of respondents' latent trait scores
- Item performance comparison
- Interpretation of leadership mentality levels
